# sshmcp v0.3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task.
> Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Port-forward tools, OpenBSD pledge, optional command
allowlist.

**Architecture:** `forward_manager_t` mirrors the session manager
on the v0.2 streaming surface; `harden()` is a new CRTP no-op hook
with an OpenBSD pledge body; allowlist is a pure checker gating
exec before cwd-wrapping.

**Tech Stack:** unchanged.

**Spec:** `docs/superpowers/specs/2026-08-17-sshmcp-v03-design.md`

## Global Constraints

- All v0.1/v0.2 policies. Existing goldens frozen except
  tools/list (re-bless, inspect: 6 tools).
- New constants: `MAX_FORWARDS = 8`.
- Build `ci-windows-msvc` (/WX) locally before push.
- Scripts with escape-laden code via Write tool, never Bash
  heredocs.

### Task 1: allowlist checker + exec gating

**Files:** Create `include/sshmcp/allow.hpp`,
`regress/unit/test_allow.cpp`; modify `types.hpp` (config_t
`allow`), `config.hpp` (parse `SSHMCP_ALLOW`), `tools.hpp` (gate
both exec paths), `test_config.cpp`, `test_tools.cpp`,
CMakeLists.

**Interfaces:**
```cpp
// allow.hpp
auto parse_allow(std::string_view text)
    -> std::vector<std::string>;            // comma-split, trim
auto check_allowed(std::string_view command,
                   std::vector<std::string> const& allow)
    -> std::expected<void, error_t>;
```
Rejected syntax when allow non-empty: `;` `&&` `||` `|` `&`
backtick `$(` newline. First token (whitespace-delimited) must be
in `allow`. Empty list → always ok. `config_t` gains
`std::vector<std::string> allow;`. In `exec_tool_t::invoke`,
after the command is read and BEFORE session/one-shot dispatch:
```cpp
auto const allowed =
    check_allowed(command, context.config.allow);
if (!allowed) {
    return error_result("exec: " + allowed.error().message);
}
```

- [ ] Tests: empty list passes `rm -rf /`; `{"git","ls"}` passes
  `git status`, rejects `rm x` naming `rm`; rejects each of
  `git a; git b`, `git a && b`, `ls | wc`, `echo `+backtick,
  `echo $(x)`, `git a & `, embedded newline — each error message
  contains the offending fragment; tabs/leading spaces tokenize.
  Config test: `SSHMCP_ALLOW="git, make ,ls"` →
  `{"git","make","ls"}`. Tool test: gated one-shot and gated
  session path (fake session_exec never called on reject).
- [ ] Implement, gate green, `feat: command allowlist guardrail`.

### Task 2: forward manager

**Files:** Create `include/sshmcp/forward.hpp`,
`regress/unit/test_forward.cpp`; modify `types.hpp`
(`MAX_FORWARDS`, `forward_open_fn_t`, `forward_close_fn_t`,
context fields), `ssh.hpp` (`build_forward_argv`), `test_ssh.cpp`,
CMakeLists.

**Interfaces:**
```cpp
// ssh.hpp
auto build_forward_argv(config_t const& config, int local_port,
                        std::string_view remote_host,
                        int remote_port)
    -> std::vector<std::string>;
// = ssh_exe + {"-N","-o","BatchMode=yes"} + ssh_args +
//   {"-L", "127.0.0.1:<lp>:<rh>:<rp>", target}

// forward.hpp
template <typename PlatformType>
class forward_manager_t {
    forward_manager_t(PlatformType& platform, config_t config);
    auto open(int local_port, std::string_view remote_host,
              int remote_port)
        -> std::expected<std::string, error_t>;  // success text
    auto close(int local_port) -> bool;
};
// types.hpp
using forward_open_fn_t = std::function<std::expected<
    std::string, error_t>(int, std::string_view, int)>;
using forward_close_fn_t = std::function<bool(int)>;
```
`open`: duplicate port → error `forward already open: <lp>`; cap
8 → error naming live ports; spawn via
`platform.stream_spawn(build_forward_argv(...))`; then health
loop: read STDERR slices until 500 ms elapsed or chunk with
`is_closed` — closed → `stream_kill`, error `forward failed:` +
collected stderr; deadline passes with process alive → store,
return `forwarding 127.0.0.1:<lp> -> <rh>:<rp>`.

Mock reuse (v0.2 pattern): mock whose `stream_read(STDERR)`
returns empty open chunks → success path (loop must exit by
deadline, keep it 500 ms real time — acceptable, two such waits
max); failing mock returns `{data:"bind: in use", is_closed:
true}` → error path carries text.

- [ ] Tests: argv layout exact; open success; open failure text;
  duplicate; cap (error names ports); close known/unknown; close
  kills child.
- [ ] Implement, green, `feat: port forward manager`.
